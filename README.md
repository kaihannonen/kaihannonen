## Editors

I have built many browser-based 2D editors, including a couple of vector-based editors with tools for Bezier curves (cubic and quadratic), lines, shapes, undo/redo and layers. They typically include visual editing features such as scaling, rotating, sending to back, bringing to front and duplicating.

Some of the editors are programmable, typically with JavaScript to control the view, animate elements or define actions based on user activity.

At Mimid.io I built a browser-based text editor similar to Google Docs, but also programmable with simple spreadsheet-style formulas and able to import multiple CSV files into a document. Users could then define rules based on the CSV data. This made it possible to create printable documents from fresh data and to generate new PDFs through an API call using the latest CSV data, making it a useful reporting tool. The editor included full text editing, print pagination, charts, images, undo/redo, live versioning and the ability to revert to older versions.

I have also built visual block-level editors, including one used to create email campaigns, landing pages and banners. That editor was built with Vue 3 and Zustand. Users could build campaigns visually by dragging blocks into the editing area; the editor serialized the content to JSON, and the back end rendered that data into the required output.

## AI and agentic development

I have used Claude Code, OpenCode, Cursor, Replit, Crush and Kilo Code heavily in design and development work.

At a defence technology company, I built an authenticated MCP (Model Context Protocol) server that indexes Git documents, splits and indexes large hardware specifications, gives Claude Code deep electronics context, and controls servers and custom devices. It has per-feature authorization and explicit tool surfaces so agents can act on real systems without exposing everything at once.

At a global design brand, I built a production AI product-matching service that compared user-uploaded photos with its products using LLM/NLP APIs. I have also worked with OpenAI APIs, LLM integrations, NLP and AI-assisted product development.

I have a strong working understanding of the practical landscape around agents: harnesses, MCP tools, context management, permissions, sandboxes, local vs remote orchestration, hosted vs self-hosted platforms, durable workflows and eval loops. I care about the unglamorous parts — tool contracts, failure paths, observability, cost and control — because that is where agent systems usually succeed or fail.
